# PRD 인수 기준 전체 점검

점검일: 2026-10-25 (한국 시간). 기준: [PRD.md](../PRD.md) AC 1~15. 이 문서는 **일반 모드에서 실제 실행한 검증 결과**다. `demo`는 서버 fixture, `mock`은 Vitest의 가짜 외부 응답 또는 Playwright의 요청 가로채기, `실제 API`는 KOBIS, `실제 DB`는 기존 Supabase 저장본을 뜻한다. mock 통과를 실제 연동 통과로 간주하지 않는다.

## 실행한 명령과 환경

`package.json`에 등록된 스크립트만 npm 명령으로 사용했다. `npm run test` **28개 통과**, `npm run test:e2e` **9개 통과**, `npm run lint` **통과**, `npm run typecheck` **통과**, `npm run build` **통과**. Playwright는 `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3101`로 별도 실행한 **demo** 프로덕션 서버를 검사했다. 비밀값을 명령·문서·출력에 기록하지 않았다.

`npm run verify:data -- --date=2026-09-06 --period=daily`는 실제 DB 읽기와 실제 KOBIS 재조회를 수행했다. **현재 KOBIS와 저장본은 일치**했지만, 저장 당시의 로컬 원본 기록이 없어 그 비교는 불가했고 명령의 종료 코드는 **1**이었다. `weekly`·`weekend`에 대한 같은 읽기 전용 명령에서는 해당 날짜의 저장본이 없었다. 이 명령들은 저장 RPC를 호출하지 않는다.

## 지표 수동 기대값 ↔ 실제값

아래 기대값은 fixture의 영화별 관객 원자료에 10,000원을 곱해 별도로 계산했으며 구현 함수의 출력을 정답으로 복사하지 않았다. 표시 단위는 정수 합산 후 변환한다.

| 항목 | 손계산 기대값 | 실행 결과 |
| --- | --- | --- |
| 9/7 관측 매출 | `(1,000 + 900 + 600)명 × 10,000원 = 25,000,000원` → 0.25억 원 | 단위 테스트 25,000,000원; 브라우저 0.25억 원 |
| 9/8 관측 매출 | `(1,100 + 1,200 + 650)명 × 10,000원 = 29,500,000원` → 반올림 0.30억 원 | 단위 테스트 29,500,000원; 브라우저 0.30억 원 |
| 두 날짜 합계·관객당 매출 | 25,000,000 + 29,500,000 = **54,500,000원**; 2,500 + 2,950 = **5,450명**; 54,500,000 ÷ 5,450 = **10,000원/명** | 단위 테스트 54,500,000원·5,450명·10,000원/명; 브라우저 관객당 10,000원/명 |
| 두 날짜 영화별 매출 | `DEMO001` 10,000,000 + 11,000,000 = **21,000,000원**; `DEMO002` 9,000,000 + 12,000,000 = **21,000,000원**; `DEMO003` 6,000,000 + 6,500,000 = **12,500,000원** | 단위 테스트에서 세 합계와 동률 코드 순서 일치 |
| 숫자 문자열 | 900원 + 1,000원 = **1,900원**, 큰 값이 앞 | 단위 테스트 1,900원·`HIGH`, `LOW` 순서 |

## 미완료 항목과 중단 조건

- **AC 1:** 실제 KOBIS 주간·주말 요청의 화면·원본 기간 대조가 남았다. 이번 점검에서는 저장본이 없는 날짜에 운영 DB 쓰기를 유발하는 조회를 하지 않았다. mock 결과를 실제 API 결과로 올려 쓰지 않는다.
- **원본 대조:** `verify:data`의 저장 당시 로컬 원본 기록이 없어 종료 코드 1이다. 현재 KOBIS와 기존 DB 값의 일치만 확인했다. 사라진 기록을 리팩토링으로 복원할 수 없다.
- **AC 14:** 브라우저 요청·로그·배포 산출물 전수 검사가 남았다.
- **AC 15:** [Vercel Hobby 공식 설명](https://vercel.com/docs/plans/hobby)은 개인·비상업적 사용으로 제한한다. [Supabase Free 공식 요금표](https://supabase.com/pricing)는 무료 2개 활성 프로젝트, DB 500MB 및 1주 비활동 시 중지를 안내한다. [KOBIS 이용안내](https://www.kobis.or.kr/kobisopenapi/homepg/board/findServiceGuideList.do)는 발급 키 사용을 요구하고, [KOBIS 이용약관 제6조](https://www.kobis.or.kr/kobisopenapi/homepg/board/findProvisionInfo.do)는 결과의 복제·저장을 금지한다. 현재 캐시 저장 경로가 이 조건과 충돌하므로 배포 적합 판정은 **실패**다. 이용 허락의 별도 근거 또는 저장하지 않는 설계 변경이 필요하다. 이 문제는 기능을 그대로 둔 구조 리팩토링만으로 통과시킬 수 없으므로 코드 변경과 배포를 진행하지 않았다.

AC 2는 재현 테스트가 먼저 실제 실패했고, 유효한 조회 기능을 유지한 채 입력 변경의 검증 경계를 정리한 뒤 전체 스크립트 검사를 재실행했다. AC 15는 외부 약관과 현재 저장 기능의 충돌이므로 거짓으로 통과하는 테스트를 추가하지 않았다. 나머지 미실행 항목도 성공으로 합산하지 않는다.
